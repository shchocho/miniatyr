# 디자인 시스템 — "쇼룸"

조용한 바탕 위에서 3D 장면 하나가 주인공입니다. 표면은 그림자 대신 경계선으로 나누고, 떠 있는 것(토스트·검색·3D 위 카드)만 그림자를 가집니다. 토큰과 컴포넌트는 모두 `styles/app.css` 에 있습니다.

이전 시스템("작업대": 모눈 바탕, 키캡 버튼, 유리 패널, 노란 테이프)에서 바꾼 이유는 [PROJECT_AUDIT.md](../PROJECT_AUDIT.md)에 있습니다.

## Project DNA

- **대상·목적**: 가구 미니어처를 직접 만드는 사람. 가구를 고르고 → 도면·재단표·조립 순서를 따라 만든다.
- **분위기**: 모던 쇼룸. 화면은 물러나고 가구(3D·썸네일·도면)가 앞에 선다.
- **경험 레이어**: 홈의 스크롤 연출과 3D 쇼룸은 Brand, 컬렉션·워크벤치·만드는 법은 Product, 스케일 랩·내 공방은 Utility(장식 모션 없음).
- **강조색**: 소나무 녹색 하나. 밝은 화면 `#2f5d46`(바탕 대비 6.9:1), 어두운 화면 `#8fc7a4`. 커팅 매트의 초록과 같은 계열이라 3D 장면과 이어진다.
- **주 행동**: 잉크색 버튼(`.btn--mat`), 화면에 하나. 강조색으로 채운 버튼은 없다.
- **글자**: IBM Plex Sans KR 한 가족 + IBM Plex Mono(치수·순번). Google Fonts 에서 불러온다. 아티팩트 묶음(`npm run artifact`)이 Google Fonts 링크만 가져갈 수 있고, 도면 시트(SVG·PDF)가 같은 글꼴을 쓰기 때문이다. 폭이 넓은 표제 글꼴(Archivo)은 뺐다.
- **어두운 화면**: 선택자는 `[data-theme="dark"]` 하나. `main.js` 가 시스템 설정을 따를 때도 `data-theme` 을 `light`/`dark` 로 정해 준다.

## 3D 쇼룸

- **룸 세트**: 방마다 벽 색 하나(포인트)와 바닥재 하나. 가구 마감은 벽과 대비되게 고른다.
- **이름표(`.room__chip`)**: 뒷벽 위의 버튼. 누르면 그 방으로 이동. 가장 가까운 방은 테두리를 진하게.
- **강조**: 가구에 올리면 15cm 들리고 발밑에 마스킹테이프 색 타일이 깔린다(장면 안의 물건이라 노랑을 그대로 둔다). 필터에 걸린 가구에는 같은 색 핀.
- **컷어웨이**: 카메라가 벽 바깥으로 가면 그 벽을 낮춘다.
- **빛·배경**: 따뜻한 키 라이트 하나 + 약한 보조광. 장면의 바탕 회색은 페이지 바탕과 같은 따뜻한 중립색 계열이다.

## 원칙

1. **3D가 주인공**: 사진 프레임은 한 화면에 하나. 나머지는 조용하게.
2. **없어도 되면 뺀다**: 모눈 바탕, 유리·흐림, 기울어지는 카드, 번쩍임, 반복되는 화살표 움직임, 제목 위 장식 라벨은 뺐다.
3. **강조는 하나**: 소나무 녹색은 선택·현재 단계·진행·포커스·링크에만. 버튼을 칠하지 않는다.
4. **숫자는 계측기처럼**: 치수와 순번은 고정폭 글자.
5. **경계선으로 나눈다**: 그림자는 떠 있는 것만.
6. **동작 줄이기 존중**: `prefers-reduced-motion` 에서 전환을 끈다.
