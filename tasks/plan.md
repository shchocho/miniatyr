# 실행 계획 — 3D 프린트로 실제 미니어처 만들기

작성: 2026-11-17 · 근거: [docs/PRINT_SIMULATION.md](../docs/PRINT_SIMULATION.md)(내부 로직·시뮬레이션) · 할 일: [todo.md](todo.md)

## 개요

지금의 내보내기는 "모델을 그대로 STL 로 쏟아 내는" 단계다. 완성형은 부품 껍질을 겹친 채로 내보내고, 키트는 부품마다 가장 얇은 축을 위로 눕혀 200mm 판에 줄지어 놓는다. 출력 가능성 점검은 "0.8mm 보다 얇은가" 한 줄이고 결과를 바꾸지 않는다.

목표는 **사용자가 고른 프린터와 축척에서, 서포트 없이 눕혀 뽑아, 사라지는 부품 없이, 기호를 보고 맞춰 끼우면 도면 치수대로 서는 키트**다. 도면·재단표(손으로 만드는 길)는 건드리지 않고, 그 옆에 "출력용 변환" 층을 하나 둔다.

```
모델(단일 소스, 실물 mm) ─┬─ 도면·재단표(그대로)
                          └─ printModel(모델, 프린터)        ← 새 층
                               ├ 두께·지름 보정(B1·B2), 투명판 정책(B3)
                               ├ 부품 자세(C1–C3), 큰 부품 나누기(D4)
                               ├ 위치잡이(D2), 기호 새기기(C5)
                               └ 판 배치(C4) → STL·3MF(E1) → 시뮬레이션(A1·F)으로 점검
```

## 시뮬레이션이 바꾼 우선순위

처음 생각한 순서는 "3MF → 결합 → 미리보기"였다. 100종 × 5축척을 돌려 보니 순서가 달라졌다.

| 시뮬레이션에서 본 것 | 그래서 |
| --- | --- |
| 1:12 에서 28종이 FDM 으로 세워 뽑으면 **부품이 사라진다**(눕히면 한 층짜리로 남음). 원인 72%가 3mm 뒤판(0.25mm)과 서랍 바닥 | 두께 보정(B1)이 맨 앞. 재료 맞춤(`fit`)은 목공 규격이라 출력 규칙이 아니다(켜도 5종이 남음) |
| 조립형으로 세워 뽑으면 서포트가 부품의 수 배(BILLY 1:12 ≈ 9배, ADDE ≈ 22배) | 기본 출력 방식은 **키트**. 조립형은 블록형 가구(소파 등)에만 권한다 |
| 키트에서 가구당 평균 3.5개 부품이 굴러가는 자세(원기둥 186, 철사 58, 구슬·구 61) | 원형 부품 자세(C2·C3)를 별도 작업으로 |
| 1:6 에서 판(256mm)보다 큰 부품 221개(31종), 조립형은 67% 만 판에 들어감 | 큰 부품 나누기(D4)는 1:6 을 지원할 때만. 1:12 를 먼저 |
| 1:24 에서 FDM 은 63% 만 온전, 레진은 1:12 를 전부 소화 | 프린터 프로파일(A2)을 먼저 두고 모든 판단을 프로파일에 묶는다 |
| 겹친 부품 껍질은 합집합으로 계산해야 부피·서포트가 맞다 | 시뮬레이터는 감긴 수(winding)로 합집합을 낸다. 내보내기는 3MF 부품 분리로(E1) |

## 기준 프린터 (2026-11-17 결정)

사용자가 특정 기종 없이 "대표적인 3D 프린터"로 정했다. 모든 판단과 기본값은 아래 프린터에 맞춘다.

| 항목 | 값 | 이유 |
| --- | --- | --- |
| 방식 | FDM(필라멘트) | 가정용으로 가장 흔하다. 레진처럼 세척·경화·환기가 필요 없다. 1:12 는 두께 보정(B1)만 하면 FDM 으로 충분하다 |
| 노즐 | 0.4mm | 거의 모든 기종의 기본 노즐. 최소 형상 0.3mm · 튼튼한 벽 0.8mm(2줄) |
| 판 | 256 × 256 × 256mm | Bambu Lab A1·P1S 급. 1:12 조립형 100% 가 들어가고 키트는 평균 1.13장 |
| 재료 | PLA | 가장 흔하고 다루기 쉽다. 비중 1.24 로 무게 계산 |
| 층 높이 | **0.12mm**(기본) · 0.2mm(빠르게) | 1:12 키트에서 0.2mm 면 105개 부품이 한 층짜리로 나오고 0.12mm 면 0개. 시간은 약 1.7배 ([시뮬레이션 6절](../docs/PRINT_SIMULATION.md)) |
| 기본 축척 | 1:12 | 이 판에서 조립형·키트 모두 판 하나에 들어가는 가장 큰 축척. 1:6 은 나누기(D4)가 필요 |

다른 판 크기(180 · 220 · 250×210)와 레진은 A2 의 선택지로 둔다. 레진의 이점은 1:24 이하에서 커지므로 그때 다시 본다.

## 설계 결정

- **출력용 변환은 별도 층이다.** `printModel()` 은 모델을 복사해 고친다. 도면·재단표·조립 단계는 원래 모델에서 나온다(기존 테스트가 지킨다).
- **안쪽으로만 두껍게.** 부품의 분해 방향(`ex`)이 바깥이므로 그 반대로 두께를 키운다. 가구의 바깥 크기와 맞물림이 바뀌지 않는다.
- **불리언 없이 먼저.** 위치잡이·기호·이음은 덧붙이는 형상으로 시작한다. 구멍(CSG)은 조사(D3) 뒤에 정한다.
- **판단의 기준은 시뮬레이터 하나.** sweep 표(`docs/print-sim/sweep-summary.json`)를 기준선으로 두고 작업마다 나빠지지 않는지 본다.
- **의존성 0 유지.** 시뮬레이터·3MF·글자 새기기 모두 직접 쓴다(지금 저장소의 원칙).

## 작업 순서(요약)

| 단계 | 작업 | 확인 지점 |
| --- | --- | --- |
| A 기반 | A1 시뮬레이터 코어화 · A2 프린터 프로파일 | 테스트 통과, sweep 기준선 그대로 |
| B 사라짐 없애기 | B1 두께 보정 · B2 원형 최소 지름 · B3 투명판 정책 · B4 출력 점검 보고 | 1:12 FDM 100%, 1:24 95%+ · **시범 출력 1(BILLY 키트)** |
| C 눕혀 뽑는 키트 | C1 판·블록 자세 · C2 원형 자세 · C3 철사 프레임 · C4 판 배치 · C5 기호·판 지도 | 키트 돌출 ≈ 0 · **시범 출력 2(POÄNG·ADDE)** |
| D 맞춤 | D1 접촉 그래프 · D2 위치잡이 · D3 핀·구멍 조사 · D4 큰 부품 나누기 | 조립 오차 실측 |
| E 파일 | E1 3MF · E2 축척별 분할 · E3 파일 검증 | 세 슬라이서에서 열림 |
| F 미리보기 | F1 웹 워커 · F2 층 단면 보기 | 2초 안에 판 하나 |
| G 실물 | G1 보정 시편 · G2 시범 출력 기록 | 프로파일 값이 실측으로 바뀜 |

병렬로 할 수 있는 것: D1(접촉 그래프)과 E2(분할)는 A 와 무관하다. B 와 C 는 `printprep.js` 를 같이 고치므로 순서대로.

## 위험과 대응

| 위험 | 영향 | 대응 |
| --- | --- | --- |
| 시뮬레이터는 슬라이서가 아니다(아라크네 가변 선폭·브리지·냉각을 모름) | 중 | G1 시편으로 최소 형상·공차를 실측해 프로파일에 넣는다. 슬라이서 CLI 연동은 열린 질문 |
| 두께를 키우면 맞물리는 부품끼리 겹친다(서랍 바닥 ↔ 서랍 옆판) | 중 | 안쪽으로만 키우고, D1 접촉 그래프가 생기면 맞닿는 면을 피해서 키운다 |
| 원형 부품을 깎아 평평하게 하면 모양이 달라진다 | 하 | 깎는 면을 조립 후 안 보이는 쪽(접촉 면·아래)으로. 렌더로 확인 |
| 구멍 결합에 CSG 가 필요하다 | 중 | 덧붙이는 위치잡이로 먼저 해결, CSG 는 조사 결과로 결정(D3) |
| 판 크기·노즐은 사용자마다 다르다 | 중 | 모든 규칙을 프로파일 값으로. 하드코딩한 200mm 를 없앤다(C4) |
| 상표: IKEA 제품명을 쓴 출력물 공유·판매 | 중 | 앱은 비공식 팬 프로젝트 고지를 유지. 3MF·STL 메타데이터에도 같은 고지(E1) |

## 열린 질문(사용자)

1. ~~가지고 있는(또는 쓸) 프린터~~ → 정해짐: 위 "기준 프린터"
2. 먼저 볼 축척: 기준 프린터에 맞춰 1:12 로 시작한다(다른 말이 없으면). 1:6 은 나누기가 필요
3. 출력 뒤 마감: 도색할지, 다색(AMS) 출력으로 색을 낼지 — E1 의 색 정보 우선순위가 달라진다
4. 시범 출력을 직접 해서 사진·실측을 남겨 줄 수 있는지(G2) — 시뮬레이터 보정의 유일한 근거
